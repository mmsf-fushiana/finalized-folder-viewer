# Implementation Plan

## Tasks

- [x] 1. DLL が版と ROM 状態を自動判定できるようにする
- [x] 1.1 (P) 登録済みアドレスを破棄できるようにする
  - 版の切り替え時に古い版の監視対象を全て捨てる
  - _Requirements: 1.3_

- [x] 1.2 (P) ROM 判定モジュールを追加する
  - ヘッダミラーのゲームコードから RJ / BA / 非対応を判定する
  - melonDS の設定ファイル (toml / ini) の場所を解決し、直近の ROM パスを読む
  - 書き込み途中や空の設定ファイルでは前回値を維持する
  - ROM ファイル先頭とヘッダの一致でファイル名を確認する
  - 短時間のゼロ (Reset) を未ロードと誤判定しないデバウンスを持つ
  - _Requirements: 1.1, 1.2, 2.1, 2.3, 2.4, 3.1, 3.2, 3.3, 3.4, 3.5, 6.1_

- [x] 1.3 メインループを自動検出型に組み替える
  - 版選択待ちを廃止し、起動直後からループを回す
  - 接続中かつ未検出の間、MainRAM を定期的に自動スキャンする
  - ROM 状態の変化を検知して status を送り、版が変われば表を入れ替えてフルステートを送る
  - 同版の別ファイルに変わった時もフルステートを送り直す
  - _Requirements: 1.3, 2.2, 2.5, 6.2_

- [x] 1.4 パイプ側コマンドをスレッド安全にする
  - status 生成を 1 か所に集約し、ROM 情報フィールドを含める
  - refresh / 接続時のフルステート送信はメインスレッドへの要求フラグにする
  - rescan はメインスレッドへの再スキャン要求にする
  - write は表の入れ替えと競合しないようロック下で行う
  - setVersion を削除し、不明コマンドとして応答させる
  - _Requirements: 1.4, 6.3, 6.4_

- [ ] 1.5 DLL をビルドし両方の melonDS フォルダへ配置する (1.x へ配置済み、0.9.5 は melonDS 終了後)
  - Release x64 でビルドし、旧 DLL を退避してから差し替える
  - 旧フロントのまま値が流れることを確認する
  - _Requirements: 6.1, 6.4_

- [x] 2. プロトコル仕様を更新する
- [x] 2.1 status の新フィールド、setVersion の廃止、rescan の意味変更、送信タイミングを仕様書に反映する
  - _Requirements: 1.4, 2.2, 3.3, 3.4_

- [x] 3. Electron から手動バージョン通知を取り除く
- [x] 3.1 (P) パイプクライアント・preload・main の setVersion 経路を削除する
  - _Requirements: 1.4, 6.4_

- [x] 4. UI が ROM 状態に反応するようにする
- [x] 4.1 store に ROM 状態を持たせる
  - status から romLoaded / romCode / romVersion / romFile / romPath を保存する
  - 版やファイルが変わった時に値系をリセットする
  - 切断時に ROM 情報と値をリセットする
  - 購読関数から版引数と setVersion 送信を外す
  - _Requirements: 2.5, 4.6_

- [x] 4.2 デスクトップ専用レイアウトで購読・遷移・キャプションを制御する
  - アプリ生存中 1 か所で gameAPI を購読する
  - 版が判明したらモニター画面へ遷移し、別版へ変わればその版へ遷移する
  - 非対応 ROM になっても画面は留まる
  - キャプションを「アプリ名 - ファイル名 [版]」形式で更新する
  - _Requirements: 4.2, 4.3, 4.4, 4.6, 5.1, 5.2, 5.3_

- [x] 4.3 待機画面を 2 段構成にする
  - バージョン選択ボタンと自前の購読・再スキャンループを削除する
  - 非対応 ROM の場合はファイル名付きのヒントを出す
  - _Requirements: 4.1, 4.5_

- [x] 4.4 モニター画面から購読・リセットを外し、状態チップを ROM 情報表示にする
  - _Requirements: 4.4, 4.6_

- [x] 4.5 文言 (日本語 / 英語) を更新する
  - 版選択に関する文言を削除し、ROM 読み込み・非対応 ROM の文言を追加する
  - _Requirements: 4.1, 4.5_

- [ ] 5. 統合確認
- [x] 5.1 型検査とビルドを通す
  - _Requirements: 4.6_

- [ ] 5.2 melonDS 1.x / 0.9.5 で ROM ロード・切り替え・Reset・再起動を確認する
  - _Requirements: 1.1, 2.2, 2.3, 3.5, 4.2, 4.3, 5.1, 6.1_
